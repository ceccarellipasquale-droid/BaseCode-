# BaseCode

Sitio web de BaseCode, agencia de desarrollo y diseño web.

## Estructura

- `index.html` — página principal (hero, servicios, proceso, testimonios, planes, FAQ, contacto)
- `privacidad.html` — política de privacidad
- `terminos.html` — términos de servicio
- `assets/` — logo y otros recursos estáticos
- `DESIGN.md` — sistema de diseño (colores, tipografía, espaciado)

## Stack

HTML + Tailwind CSS (vía CDN) + JavaScript vanilla. Sin build step, listo para desplegar como sitio estático.

## Deploy

Desplegado en [Vercel](https://vercel.com) como sitio estático.
